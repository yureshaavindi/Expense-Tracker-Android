# Expense Tracker – Android Application

An Android application developed using Java, XML, SQLite, and RecyclerView.

## Features
- Add daily income and expenses
- View saved financial records
- Edit and delete records
- Calculate income, expenses, and balance
- View daily, weekly, and monthly financial summaries
- Store records locally using SQLite

## Technologies Used
- Java
- XML
- SQLite
- RecyclerView
- Android Studio
